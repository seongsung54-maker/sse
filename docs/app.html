시작하기

컴퓨터에 아무것도 설치하지 않습니다.
ChatGPT 앱만 있으면 됩니다.

먼저 챙길 것

  • ChatGPT 앱이 깔린 컴퓨터 (윈도우·맥) — Plus 이상 계정 (무료 계정은 안 됩니다)
  • OpenAI API 키
  • 워드프레스 정보 — 주소 · 관리자 ID · 애플리케이션 비밀번호
  • 수강 코드 — 자료실 공지
  • 공지에서 받은 키설정.txt · 제목.txt 두 파일

휴대폰·태블릿으로는 작업할 수 없습니다. 이 안내서는 휴대폰으로 봐도 됩니다.

1

키설정.txt 채우기

공지에서 받은 키설정.txt 를 메모장(맥은 텍스트 편집기)으로 열고, 한 줄에 하나씩 순서대로 넣고 저장하세요. 줄 사이를 띄워도 됩니다. 수강 코드는 여기 넣지 않습니다 (코덱스가 채팅으로 따로 물어봅니다).

sk-여기에붙여넣기            ← OpenAI 키

https://내사이트.com          ← 사이트 주소

워드프레스관리자아이디         ← 관리자 아이디

xxxx xxxx xxxx xxxx xxxx xxxx ← 애플리케이션 비밀번호
사이트가 여러 개면 아래에 주소 → 아이디 → 비밀번호 순서로 이어서 적으세요 (최대 10개). 적은 개수만큼 등록됩니다.
이 파일은 비밀번호입니다 단톡방·채팅방에 올리지 마세요. 코덱스 채팅창에만 넣습니다.
2

제목.txt 준비하기

승인글 제목을 한 줄에 하나씩 적은 txt 파일. 1개만 있어도 되고 150개여도 됩니다.

형식은 아무거나 됩니다 1. 제목 처럼 번호가 붙어 있어도, 카테고리·설명이 섞여 있어도 프로그램이 번호 붙은 제목만 알아서 골라냅니다. "주제 뽑기" 로 받은 150개 파일을 그대로 넣으면 됩니다.
3

코덱스 열고 빈 폴더 고르기

ChatGPT 앱 → 왼쪽 Codex → 새 채팅.
바탕화면에 빈 폴더 하나 만들고(이름은 아무거나, 예: 메킷키트) 작업 폴더로 그 폴더를 고릅니다.

폴더는 한 번 만들면 계속 같은 폴더 다음부터는 새 채팅에서 이 폴더를 다시 고르면 됩니다. 폴더 안 파일은 건드리지 마세요.
4

설치 — 이 한 줄

깃허브 makeit-edu/makeit-middle-kit 저장소의 README 를 읽고 거기 적힌 대로 설치해

30초쯤 뒤 코덱스가 이렇게 말합니다.

“설치가 끝났어요. 이제 처음 한 번만 하는 키 설정입니다.
먼저 강의 자료실 공지에 있는 수강 코드를 알려 주세요.”

수강 코드를 치면 → “수강 코드 확인됐어요. 이제 공지에서 받은 키설정.txt 파일을 여기에 끌어다 놓거나, 그 내용을 그대로 붙여넣어 주세요.”

"설치를 진행할까요?" 라고 물으면 진행해 라고 답하세요. 코덱스가 인터넷에서 받은 프로그램을 처음 실행하기 전에 한 번 확인하는 것입니다.
"README 를 읽고" 가 꼭 들어가야 합니다 주소만 주고 "설치해" 라고 하면 코덱스가 저장소를 통째로 내려받으려다 실패합니다.
"준비 중입니다. 10초 뒤 다시" 가 나오면 앱을 막 켠 직후에 그럽니다. 10초 뒤 같은 문장을 다시 치세요. 계속 그러면 ChatGPT 앱을 완전히 끄고(Cmd+Q / 창 닫기) 다시 켜세요.
5

키설정.txt 끌어다 놓기

1번에서 채운 키설정.txt 를 채팅창에 끌어다 놓거나, 내용을 복사해 붙여넣고 엔터.

코덱스가 읽어서 확인하고 저장합니다.
“OpenAI 키 확인 · 워드프레스 연결 확인. 키 설정이 끝났어요!
이제 승인글 제목 파일(txt)을 여기에 끌어다 놓거나, 제목을 한 줄에 하나씩 붙여넣어 주세요.”
틀린 줄이 있으면 "OpenAI키가 올바르지 않아요", "워드프레스에 연결이 안 돼요: …" 처럼 어느 줄인지 알려 줍니다. 그 줄만 고쳐 저장하고 다시 끌어다 놓으세요. 사이트가 여러 개면 "1번 사이트: …" 처럼 사이트별로 알려 줍니다.
워드프레스가 계속 안 될 때 비밀번호를 연속으로 틀리면 사이트가 잠시 문을 잠급니다. 20~30분 뒤에 다시 끌어다 놓으세요.
6

제목.txt 끌어다 놓기

2번에서 준비한 제목.txt 를 채팅창에 끌어다 놓거나 제목을 붙여넣고 엔터.

“제목 150개 받았어요. (카테고리 5개)
워드프레스에 이미 있는 글 12개는 빼고, 새로 쓸 수 있는 제목이 138개예요.
임시글 몇 개 뽑아드릴까요? (예: 1개, 10개)”
이미 쓴 글은 알아서 빠집니다 워드프레스에 같은 제목이 있으면(임시글·비공개 포함) 세지 않고, 만들 때도 새 제목만 고릅니다. 예전에 쓴 글도 마찬가지예요.
사이트가 여러 개면 "먼저 1번 사이트 제목부터 주세요" → 다음 "2번 사이트 제목" 순서로 사이트마다 따로 받습니다.
7

몇 개 만들지 답하기

처음에는 1개로 확인하고, 괜찮으면 10개, 20개씩 늘리세요. 사이트가 여러 개면 사이트마다 그 개수씩 만듭니다.

글 하나에 2~4분 걸리고, 글마다 이렇게 보입니다.

[■■■■■■□□□□□□□□□□□□□□]  30% │ 3/10번째 글 │ 완료 ✅
💰 이 글: 토큰 12,500개 · 약 46원
   지금까지 3개 · 약 140원
날짜는 알아서 흩어 줍니다 기본이 하루 3개 · 최소 3시간 간격 · 시각 무작위입니다. 10개를 만들면 오늘부터 3~4일에 걸쳐 배치되고, 임시글에서 발행을 누르면 그 시각에 예약 공개됩니다. 바꾸고 싶으면 그냥 말하세요: “하루에 5개씩”, “간격 6시간 이상”, “지금 시각으로 바로”.
8

끝나면 확인하고 발행

다 끝나면 코덱스가 제목·발행 날짜 표와 이번에 쓴 돈을 정리해 줍니다.

글은 전부 임시글입니다. 워드프레스 관리자 → 글 → 임시글에서 확인한 뒤 발행 버튼은 직접 누르세요.

다음부터는 코덱스 새 채팅 → 같은 폴더 → 승인글 자동화 시작해 → "몇 개?" → 개수. 그게 전부입니다.
제목이 떨어지면 코덱스가 제목 파일을 다시 달라고 합니다.
ChatGPT Plus 사용량은 코덱스 앱 왼쪽 아래 계정 → 설정 → 사용량에서 볼 수 있어요. 프로그램은 이 숫자를 읽을 수 없습니다.
