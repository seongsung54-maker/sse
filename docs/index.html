먼저 챙길 것

  • 크롬이 깔린 컴퓨터 (노트북·데스크톱)
  • ChatGPT Plus 이상 계정 (무료 계정은 안 됩니다)
  • OpenAI API 키 — 받는 법 (10분)
  • 워드프레스 정보 — 주소 · 관리자 ID · 애플리케이션 비밀번호
  • 수강 코드 — 자료실 공지

휴대폰·태블릿으로는 작업할 수 없습니다. 이 안내서는 휴대폰으로 봐도 됩니다.

1~3분 기다리기

검은 창에 영어 글자가 빠르게 흘러갑니다. 멈춘 게 아닙니다.

아래 화면이 나오면 끝난 것입니다.

━━━━━━━━━━━━━━━━━━━━━━━━━ ✅ 준 비 완 료 설치가 전부 끝났습니다 이제 이 검은 창에 아래 순서대로 입력하세요. 1) 키설정 2) 시작 ━━━━━━━━━━━━━━━━━━━━━━━━━
문서가 잠깐 보이더라도 끝난 게 아닙니다 준비가 끝나면 검은 창이 화면을 꽉 채우면서 앞으로 나옵니다. 그 전에 문서가 잠깐 보이는 건 아직 진행 중이라는 뜻이에요. 초록색 “준 비 완 료”가 검은 창에 뜨는 것만 보세요.
6

열쇠(키) 넣기

검은 창을 한 번 클릭하고 키설정 치고 엔터.

수강 코드 → OpenAI 키 → 충전한 금액 → 워드프레스 사이트 정보 순서로 물어봅니다. 아직 없는 건 엔터로 건너뛰면 됩니다.

충전한 금액(달러)을 넣으면 글마다 남은 돈이 보입니다 OpenAI 에 충전한 금액을 숫자로 넣어 두면(예: 10), 글 하나 만들 때마다 이 글에 쓴 토큰과 돈 · 충전액의 몇 % · 지금까지 쓴 돈 · 남은 돈을 보여 드려요. 다시 충전했으면 키설정 을 다시 돌려 새 금액을 넣으면 그때부터 새로 셉니다.
OpenAI 키를 아직 안 받았다면 먼저 받고 오세요. 10분이면 됩니다. → OpenAI 키 받는 법 (별도 페이지)
화면에 점(••••)만 보이는 게 정상 키는 비밀번호라 가려집니다. 한 번만 붙여넣고 엔터.
사이트는 최대 10개 — 몇 개 넣을지 먼저 물어봅니다 1개만 있으면 1 을 넣으세요. 도중에 그만하려면 도메인 자리에 끝 치고 엔터.
이미 넣어둔 사이트는 맨 위 ‘현재 상태’에 주소까지 보입니다.
워드프레스는 세 가지가 다 맞아야 넘어갑니다 주소 · 관리자 ID · 애플리케이션 비밀번호(보통 24글자). 실제로 접속해 보고 안 되면 그 자리에서 다시 물어봅니다.
연속으로 틀리면 사이트가 잠시 문을 잠급니다 공격으로 오해하는 겁니다. 그럴 땐 20~30분 뒤에 다시 하세요. 저절로 풀립니다.

제목 넣기

왼쪽 탐색기에서 애드센스 승인글 → 01_제목넣는곳 → 사이트1제목.txt 를 클릭해 엽니다.

준비한 제목을 붙여넣고 Ctrl+S(맥 Cmd+S)로 저장하세요. 챗봇에서 받은 결과는 카테고리까지 통째로 붙여넣으면 됩니다.

제목이 없거나 더 필요하시면 AI 비서에게 “제목 뽑아줘” 라고 하세요. 주제를 같이 골라서 카테고리까지 나눈 제목 150개를 만들어 이 파일에 바로 저장해 줍니다. 이미 제목이 있으면 더할지 새로 만들지 먼저 물어봅니다.
이 파일에는 제목만 사이트 주소·아이디·비밀번호·API 키는 절대 넣지 마세요.

승인글 만들기

검은 창에 시작 으로 코덱스를 켜고 이렇게 말하세요.

승인글 자동화 시작해

처음에는 1개만 만들어 확인하고, 괜찮으면 5개 → 20개씩 늘리세요. 글은 임시글로만 저장되고 공개 발행되지 않습니다.

진행 게이지와 돈이 글마다 보입니다 [■■■■□□□□□□] 40% │ 2/5번째 글 │ 3/5단계 본문 쓰는 중 처럼 어디까지 왔는지 보이고, 글 하나가 끝날 때마다 💰 이 글에 쓴 토큰·돈 · 지금까지 쓴 돈 · 남은 돈이 찍힙니다. 남은 돈은 키설정 에서 충전 금액을 넣었을 때만 나와요.
왼쪽 탐색기의 애드센스 승인글 → 02_생성결과_확인용 → 지금_진행상황.md 를 열어 두면 게이지가 실시간으로 바뀝니다.
이미 쓴 글은 알아서 빠집니다 워드프레스에 이미 있는 제목(임시글 포함)은 건너뜁니다. 다른 기수에서 쓴 글도 마찬가지예요. 제목 파일은 그대로 두시면 됩니다.
날짜를 나눠 올리고 싶으면 그냥 말하세요 그냥 만들면 지금 시각으로 들어갑니다. 나누고 싶으면 이렇게 말하면 돼요.
· “오늘부터 하루에 1개씩 10개 만들어줘”
· “날짜도 무작위로 흩어서 20개”
시간은 따로 말 안 해도 글마다 알아서 다르게 들어갑니다.
