OpenAI 키 받기

글과 이미지를 만드는 데 쓰는 열쇠입니다.
10분이면 끝나고, 한 번만 받으면 됩니다.

시작 전에

  • 이메일 주소 — ChatGPT 쓰는 계정 그대로 써도 됩니다
  • 해외 결제 되는 카드 (비자 / 마스터)
  • 화면이 전부 영어입니다. 아래 순서대로만 따라오세요

이미 받아둔 키가 있으면 이 문서는 건너뛰어도 됩니다.

1

사이트 열기

platform.openai.com
chatgpt.com 이 아닙니다 같은 회사의 다른 사이트예요. 주소를 다시 한번 확인해 주세요.

오른쪽 위 Log in 클릭 → ChatGPT에서 쓰던 계정으로 그대로 로그인.

2

카드 등록하고 충전하기

이 키는 선불 방식이라, 카드를 넣고 조금 충전해야 작동합니다.

오른쪽 위 ⚙ (Settings) → 왼쪽 Billing
→ Add payment details → Individual(개인) → 카드 번호 입력

얼마를 넣을까요? $10 을 권해드립니다. (최소 $5)
승인글 1개에 몇십 원~백 원 정도라, $10이면 여유 있게 실습합니다.
Auto recharge 는 꼭 꺼주세요 자동 충전 기능입니다. 켜두면 모르는 사이에 결제됩니다.
3

키 만들기

왼쪽 메뉴에서 API keys → Create new secret key

이름(Name)은 아무거나 써도 됩니다. 예: weolbu
나머지는 그대로 두고 Create secret key.

sk-proj-██████████████████████████ Copy
창을 닫으면 다시 못 봅니다 지금 바로 Copy 를 누르고 메모장에 붙여넣으세요.
놓쳤어도 괜찮습니다 — 그 키는 버리고 새로 만들면 돼요. 몇 개를 만든든 무료입니다.
4

키트에 넣기

작업방으로 돌아와 검은 창에 키설정 치고 엔터.

물어보는 순서대로 붙여넣으면 됩니다.
① 수강 코드 → ② OpenAI 키 → ③ 워드프레스 정보

붙여넣어도 안 보이는 게 정상 비밀번호라 점(••••)으로만 보입니다. 한 번만 붙여넣고 엔터.
아직 없는 건 엔터로 건너뛰세요 나중에 키설정 을 다시 치면 그 값만 넣을 수 있습니다.
“모두 정상 확인!” 이 나오면 끝 건너뛴 항목은 [나중에 입력]으로 표시됩니다 — 실패가 아닙니다.

꼭 지켜주세요

키는 비밀번호입니다 채팅방·카톡·인증샷에 절대 올리지 마세요. 메모장에 옮겨둔 키도 입력이 끝나면 지우시는 게 안전합니다.
키가 새나간 것 같으면 발급 페이지에서 그 키를 삭제(Revoke) 하고 새로 만들어 키설정 을 다시 하면 됩니다.
전체 순서가 궁금하면 → 메킷 키트 시작하기 안내서
