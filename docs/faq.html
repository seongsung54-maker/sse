자주 묻는 질문

대부분은 고장이 아니라 원래 그런 것입니다.
아래에서 같은 증상을 찾아보세요.

뭐가 문제인지 모르겠을 때

  • 검은 창(터미널) 에 진단 을 치고 엔터하세요. 이 검은 창을 '터미널' 이라고 부릅니다. 아래에서는 '검은 창' 으로 적었습니다.
  • 나온 내용을 전부 복사해서 코덱스에게 붙여넣고 물어보면 됩니다.
  • 사진 말고 글자로 복사해서 올려주세요. 찾기도 쉽고 답도 빠릅니다.

작업방(검은 창)

화면이 멈췄어요. 꺼져 있어요

고장이 아닙니다. 30분 동안 안 쓰면 잠드는 절전 기능이에요.

초록색 재시작 버튼을 누르고 1분만 기다리시면 작업하던 것 그대로 다시 열립니다.

느려요. 로딩이 안 끝나요

작업방을 처음 만들 때만 몇 분 걸립니다. 정상이에요.

5분이 넘으면 새로고침 한 번 해보세요. 그래도 안 되면 작업방을 지우고 다시 만드시면 됩니다. github.com/codespaces → 내 목록에서 오른쪽 ··· → Delete → 저장소에서 새로 만들기.

다시 만들어도 작업물은 남아 있어요 저장 을 해두셨다면 그대로 돌아옵니다. 열쇠(키)만 다시 넣으시면 돼요.

작업방이 통째로 사라졌어요

30일 동안 한 번도 안 들어가면 자동으로 지워집니다.

저장 해둔 것은 새 작업방을 만들면 되살아납니다. 다만 코덱스 로그인과 열쇠 3개는 다시 넣으셔야 해요(10분쯤). 열쇠는 안전을 위해 클라우드에 보관하지 않기 때문입니다.

그래서 작업이 끝나면 저장 이 한 번이 작업물을 지켜 줍니다. 습관처럼 해주세요.

무료 한도를 다 썼대요

다음 달 1일에 저절로 초기화됩니다. 그때까지는 작업방을 쓸 수 없어요.

다 쓰고 나서 탭만 닫아두면 작업방이 계속 켜져 있는 걸로 칩니다. 끝나셨으면 저장 하고 작업방을 정지시켜 주세요.

복사 · 붙여넣기

검은 창에서 복사가 안 돼요

검은 창에서는 Ctrl+C 가 복사가 아닙니다. (하던 일을 멈추라는 뜻이에요)

마우스로 드래그해서 선택 → 우클릭 → 복사 하시면 됩니다.

붙여넣기가 안 돼요

처음에 떴던 영어 팝업에서 Block(차단) 을 누르신 겁니다.

주소창 왼쪽 자물쇠 아이콘 → 클립보드 → 허용 으로 바꾸고 새로고침하세요.

command not found 라고 나와요

글자가 조금 다르게 들어간 겁니다. 직접 타이핑하지 마시고 공지의 복사 버튼으로 복사해 붙여넣으세요.

앞뒤에 빈칸이 붙어 있어도 같은 오류가 납니다.

가입 · 로그인

깃허브 인증 메일이 안 와요

먼저 스팸함을 보세요. 네이버·다음 메일에서 특히 자주 들어갑니다.

없으면 Resend(다시 보내기)를 누르고, 그래도 안 오면 지메일(Gmail)로 가입하시는 게 빠릅니다.

링크를 누르는 방식이 아니에요 메일에 적힌 8자리 숫자를 가입 화면에 옮겨 적는 방식입니다.

Create codespace 버튼이 안 보여요

초록색 Code 버튼을 누르면 탭이 두 개 있습니다. 그중 Codespaces 탭을 눌러보세요.

그래도 안 보이면 깃허브 로그인이 풀린 겁니다. 다시 로그인하시면 나타납니다.

승인 화면에서 로그인하라고 나와요

지금 쓰는 브라우저에 ChatGPT가 로그인돼 있지 않아서 그렇습니다.

평소 쓰시는 본인 ChatGPT 계정으로 먼저 로그인한 다음, 승인을 다시 시도하세요. 가족이나 회사 계정으로 들어가 계신 경우가 많습니다.

로그인이 자꾸 빙글빙글 돌아요

여러 기기에서 로그인이 겹쳤을 때 이럽니다. 검은 창에 아래를 치고 엔터하세요.

rm .codex/auth.json

그다음 시작 을 치면 로그인 안내가 다시 나옵니다.

한참 안 썼더니 로그인이 풀렸어요

정상입니다. 8일쯤 지나면 자동으로 풀립니다. 다시 로그인하는 데 1분이면 됩니다.

열쇠(키)

열쇠를 붙여넣었는데 화면에 안 보여요

비밀번호라서 원래 안 보입니다. 한 번만 붙여넣고 엔터하세요.

안 보인다고 두 번 붙여넣으면 겹쳐 들어갑니다. 그럴 땐 키설정 을 다시 하시면 됩니다.

로그인을 했는데 왜 또 열쇠를 넣나요? 돈이 또 나가나요?

열쇠가 두 개입니다. 하는 일이 서로 달라요.

코덱스 로그인은 대화하는 비서를 부르는 열쇠입니다. 쓰시는 ChatGPT 플러스 요금에 이미 포함돼 있어서 추가 비용이 없습니다.

OpenAI 열쇠는 글과 이미지를 찍어내는 공장을 여는 열쇠입니다. 쓴 만큼만 내는데, 승인글 한 편에 몇십 원에서 백 원 정도입니다.

남은 돈은 어떻게 계산하나요? 실제 잔액과 달라요

OpenAI 는 프로그램에 잔액을 알려 주지 않습니다. 그래서 키설정 에 넣은 충전 금액에서, 그 뒤로 이 키트가 쓴 만큼만 빼서 계산합니다.

다른 곳(ChatGPT 사이트의 플레이그라운드, 다른 프로그램)에서 같은 열쇠를 쓰면 그 돈은 안 빠집니다. 정확한 잔액은 OpenAI 결제 화면에서 보세요.

다시 충전했으면 키설정 을 다시 돌려 새 금액을 넣으세요. 그때부터 새로 셉니다. 충전 금액을 안 넣으면 남은 돈 대신 쓴 돈만 보여 드립니다.

열쇠가 새나간 것 같아요

바로 그 열쇠를 지우고 새로 만드시면 됩니다. 지운 열쇠는 아무도 못 씁니다.

발급 페이지에서 해당 열쇠를 삭제(Revoke) → 새로 발급 → 검은 창에 키설정 을 다시 하세요.

지웠으니 괜찮다 — 는 안 됩니다 채팅방에서 메시지를 지워도 이미 본 사람은 되돌릴 수 없어요. 반드시 열쇠를 새로 발급받으셔야 합니다.

제목 · 글

예전에 쓰던 제목 파일이 안 보여요

예전에 내려받아 쓰시던 파일은 내 컴퓨터에 그대로 있습니다. 작업방으로 저절로 옮겨오지는 않아요.

그 폴더를 열어 내용을 복사한 다음, 작업방의 제목 파일에 붙여넣으시면 됩니다.

워드프레스 연결이 계속 안 돼요

비밀번호를 새로 발급해도 똑같다면, 값이 아니라 사이트가 막고 있는 것입니다.

작업방은 내 컴퓨터가 아니라 서버에서 돌기 때문에, 사이트의 보안 기능이 낯선 접속으로 보고 막습니다. 키설정 화면이 원인과 순서를 알려주니 그대로 따라 하시면 됩니다.

비밀번호를 여러 번 틀리셨다면 사이트가 잠시 문을 잠급니다. 20~30분 뒤에 다시 하시면 저절로 풀려요.
