글 자동으로 쓰기

키워드 하나만 말하면 코덱스가 글과 사진을 만들고
네이버에 임시저장까지 해 줍니다. 발행만 직접 누르세요.

먼저 챙길 것

  • ChatGPT 앱이 깔린 컴퓨터 (윈도우·맥) — Plus 이상 계정
  • 크롬 — 네이버 블로그 아이디로 로그인할 수 있으면 됩니다
  • 1주차에 쓰던 작업 폴더 — 키 설정이 이미 돼 있어서 다시 안 합니다
  • 1주차를 안 했다면 — 수강 코드(자료실 공지)와 채워 둔 키설정.txt (아래 상자 참고)
  • 쓰고 싶은 키워드 (예: 장수축하금 지원대상) 또는 따라 쓰고 싶은 네이버 글 주소

휴대폰·태블릿으로는 작업할 수 없습니다. 이 안내서는 휴대폰으로 봐도 됩니다.

1주차를 안 했다면 — 키 설정부터 설치하면 코덱스가 1주차와 똑같이 수강 코드를 먼저 묻고, 이어서 키설정.txt 를 달라고 합니다. 공지에서 받은 키설정.txt 를 메모장으로 열고 한 줄에 하나씩 넣어 두세요. 
sk-여기에붙여넣기            ← OpenAI 키
https://내사이트.com          ← 사이트 주소
워드프레스관리자아이디         ← 관리자 아이디
xxxx xxxx xxxx xxxx xxxx xxxx ← 애플리케이션 비밀번호
네이버 글에는 OpenAI 키만 있으면 됩니다. 워드프레스 세 줄은 승인글용이라, 아직 없으면 비워 두고 나중에 넣어도 됩니다.
1

크롬에 코덱스 확장 설치

ChatGPT 앱 → 왼쪽 Codex → 설정 → 컴퓨터 사용 → Chrome 에서 크롬 확장을 설치합니다.

설치가 끝나면 크롬 오른쪽 위 퍼즐 모양을 눌러 ChatGPT(Codex) 확장이 켜져 있는지 확인하세요. 핀(📌)을 꽂아 두면 편합니다.

한 번만 하면 됩니다 코덱스가 이 확장으로 크롬의 네이버 글쓰기 화면에 글을 넣습니다. 다른 탭·다른 사이트는 건드리지 않습니다.
2

사진 넣기 허용 켜기

크롬 주소창에 chrome://extensions 를 치고 엔터 → ChatGPT 확장의 세부정보 → 파일 URL에 대한 액세스 허용 을 켭니다.

이걸 안 켜면 사진만 빠집니다 글은 다 들어가고 사진만 안 올라갑니다. 코덱스가 "사진만 빠졌어요" 라고 알려 주면 이걸 켜세요.
3

크롬에서 네이버 로그인

크롬으로 naver.com 에 들어가 블로그 아이디로 로그인하세요. 로그인 상태 유지를 체크해 두면 다음부터 다시 안 해도 됩니다.

로그인은 직접 아이디·비밀번호·2차 인증은 코덱스에게 알려 주지 마세요. 크롬에서 내가 직접 합니다.
4

코덱스 열고 1주차 폴더 고르기

ChatGPT 앱 → Codex → 새 채팅 → 작업 폴더로 1주차에 쓰던 폴더를 고릅니다.

같은 폴더를 고르세요 1주차 키 설정(수강 코드·OpenAI 키)을 그대로 씁니다. 1주차 승인글 자동화도 이 폴더에서 계속 됩니다.
5

설치 — 이 한 줄

깃허브 makeit-edu/makeit-middle-kit 저장소의 README 를 읽고 거기 적힌 대로 설치한 뒤 네이버 글 써줘

30초쯤 뒤 코덱스가 크롬의 네이버 로그인까지 알아서 확인하고 이렇게 말합니다.

“네이버 준비됐어요! 어떤 키워드로 글을 쓸까요? (예: 장수축하금 지원대상)
따라 쓰고 싶은 네이버 블로그 글 주소를 주셔도 돼요.”
"설치를 진행할까요?" 라고 물으면 진행해 라고 답하세요. 코덱스가 인터넷에서 받은 프로그램을 처음 실행하기 전에 한 번 확인하는 것입니다.
1주차와 같은 저장소입니다 저장소 이름은 1·2·3주차 모두 makeit-edu/makeit-middle-kit 하나입니다. 이미 설치했어도 이 문장을 한 번 더 치면 최신으로 맞춰지고 바로 네이버로 넘어갑니다. "README 를 읽고" 도 꼭 넣으세요.
1주차를 안 했다면 먼저 “수강 코드를 알려 주세요” → 수강 코드 → “키설정.txt 를 끌어다 놓아 주세요” → 키설정.txt 를 채팅창에 끌어다 놓기. “키 설정이 끝났어요!” 가 나오면 이어서 네이버 준비로 넘어갑니다.
"크롬에서 네이버에 로그인해 주세요" 가 나오면 3번대로 로그인하고 채팅창에 됐어요 라고 치세요.
6

키워드 말하기

키워드를 치고 엔터. 코덱스가 글과 사진 3장을 만듭니다. 1분 안팎 걸립니다.

글 완성: 장수축하금 지원대상, 우리 부모님도 해당될까? (사진 3장)
💰 이 글: 토큰 9,880개 · 약 65원
   지금까지 네이버 1개 · 약 65원
따라 쓰기도 됩니다 잘 쓴 네이버 글 주소(blog.naver.com/…)를 주면 그 글의 순서·표·사진 배치만 참고하고 문장은 전부 새로 씁니다.
사진에는 글자가 없습니다 한글·영어·숫자 어떤 글자도 넣지 않고, 내용과 어울리는 그림만 만듭니다.
7

네이버에 쓰는 동안 지켜보기

코덱스가 크롬에 네이버 글쓰기 화면을 열고 제목·본문·소제목·표·인용구·사진을 차례로 넣습니다. 5~8분 걸립니다.

크롬 창을 건드리지 마세요 쓰는 동안 크롬 창을 화면 가득, 맨 앞에 두고 마우스·키보드를 만지지 마세요. 다른 창이 위를 덮으면 글이 안 들어갑니다.
"계속 쓰는 중이에요" 가 나와도 정상 긴 글은 두세 번에 나눠서 씁니다. 코덱스가 알아서 이어서 씁니다.
"전체 글감" 창이 잠깐 떠도 그대로 두세요 쓰는 도중 글감 창이 뜨면 프로그램이 바로 X 로 끄고, 빠진 글자까지 다시 넣고 이어서 씁니다.
8

읽어 보고 발행은 직접

“다 썼어요! 네이버에 임시저장해 뒀습니다.
크롬 화면에서 글을 읽어 보시고, 괜찮으면 오른쪽 위 ‘발행’ 을 직접 눌러 주세요.”

크롬에 열린 글을 읽어 보고 발행 버튼을 누르세요. 코덱스는 발행을 절대 누르지 않습니다.

창을 닫았다면 네이버 블로그 → 글쓰기 → 오른쪽 위 저장 옆 숫자를 누르면 임시저장 글이 나옵니다.

다음 글은 키워드만 또 말하면 됩니다. 새 채팅이면 같은 폴더를 고르고 네이버 글 써줘. 로그인·키는 다시 안 묻습니다.

코덱스가 알려 준 오류 내용을 보고, 네이버 글쓰기 탭을 닫은 뒤 다시 '네이버 글 써줘'

멈추면 코덱스가 무엇이 안 됐는지와 할 일을 알려 줍니다. 그대로 하고 다시 네이버 글 써줘 만 하면 됩니다. 쓰다 만 글은 네이버 임시저장에 남아 있으니 지워도 됩니다.
