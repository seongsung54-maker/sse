코덱스가 고치고 검사하기

코덱스가 깃허브의 참고 자료 중 필요한 것만 읽고, 작업본을 고친 뒤 스스로 검사합니다. 라이선스·광고·초기화 부분이 바뀌었거나 괄호·따옴표가 깨졌으면 ZIP 을 만들지 않고 먼저 바로잡습니다.

글자휴대폰에서 본문이 작아요. 내용은 그대로 두고 읽기 편하게 해줘.
목차목차가 본문을 가려요. 휴대폰에서 겹치지 않게 해줘.
속도이 PageSpeed 결과에서 메킷애센이 원인인 부분만 찾아줘.

이 입력란은 문장만 만듭니다. 복사해서 코덱스에 보내야 고쳐집니다.

아래는 기존 관련 글 표시를 카드로 바꾼 실제 로컬 워드프레스 시험입니다. 예시 하나일 뿐, 모든 학생이 같은 카드로 만들 필요는 없습니다.

속도 고치기 — PageSpeed Insights 쓰는 법

페이지스피드는 내 페이지의 속도와 고칠 곳을 보는 검사 도구입니다. 플러그인을 대신 고쳐 주지는 않습니다.

PageSpeed Insights 열기 ↗
  1. 고치기 전: 검사할 글 주소를 넣고 분석합니다. ‘모바일’ 결과 화면을 캡처해 둡니다.
  2. 코덱스에 주기: 캡처를 채팅창에 넣고, 메킷애센 안에서 고칠 수 있는 원인 하나를 찾게 합니다.
  3. 고친 뒤: 워드프레스에 올리고 같은 글·같은 조건에서 다시 검사합니다. 가능하면 전후 각각 3번 재고 가운데 값을 비교합니다.

성능 점수 — 모의 검사 종합 점수. 한 번의 숫자로 단정하지 않아요.

LCP — 큰 내용이 나타나는 시간.

CLS — 화면 배치가 얼마나 흔들리는지.

점수는 검사마다 달라질 수 있습니다. 실제 방문자 자료는 최근 28일 집계라 바로 바뀌지 않고, ‘데이터 없음’은 0점이 아닙니다. 광고·통계·라이선스를 빼서 점수만 올리지 않습니다. Google 측정 안내

다른 곳까지 바꾼다고 하면내가 고른 부분만 바꿔줘 라고 말하세요.

내 워드프레스에 올리기

플러그인 올리기는 내가 직접 합니다. 연습용 사이트가 있으면 거기서 먼저 해 보세요.

워드프레스 · 이동 순서
  1. 관리자 → 플러그인 → 새 플러그인 추가
  2. 플러그인 업로드 → 03_완성ZIP 의 ZIP 선택 → 지금 설치
  3. “현재 버전을 업로드한 버전으로 교체” 누르기
  4. 내 사이트의 글을 컴퓨터·휴대폰에서 다시 확인
화면이 그대로면캐시 플러그인(WP Rocket 등)이 있으면 캐시를 비우고, 휴대폰은 새로고침하세요. 올린 뒤 관리자 화면을 처음 열 때 메킷애센이 홈·메뉴를 한 번 다시 맞춥니다 (정식 업데이트 때와 같아요).
새로 설치하지 말고 ‘교체’교체 버튼이 안 보이고 새 플러그인으로 들어가면, 원본과 수정본을 함께 켜지 마세요. 폴더 이름이 원본과 같은 ZIP 이어야 교체됩니다.
오늘의 결과물받은 플러그인을 그대로 쓰는 데서 한 걸음 더 나아가, 내가 원한 대로 바뀐 메킷애센을 내 사이트에 올렸습니다.

마음에 안 들면 되돌리기

메킷애센 수정 → 01_원본ZIP넣는곳 의 원본 ZIP을 7번과 같은 방법(업로드 → 교체)으로 올리면 원래대로 돌아갑니다.

관리자 화면이 안 열리면호스팅의 파일 관리자에서 wp-content/plugins/makeit-adsense-midclass 폴더 이름을 바꾸면 플러그인이 꺼집니다. 그다음 관리자에 들어가 원본 ZIP 을 올립니다.
‘초기화’는 되돌리기가 아닙니다메킷애센의 초기화 버튼은 글·설정을 지웁니다. 되돌릴 때는 원본 ZIP 을 씁니다.

막혔을 때

ZIP 을 못 읽어요압축을 풀지 말고 ZIP 파일 그대로 채팅창에 끌어다 놓으세요. 그래도 안 되면 메킷애센 수정 → 01_원본ZIP넣는곳 에 넣고 “넣었어”.
라이선스·광고 부분이 바뀌었대요코덱스가 그 부분을 원본대로 되돌린 뒤 다시 ZIP 을 만듭니다.
다른 곳도 바뀌었어요원하지 않은 부분을 말하고 그 변경만 되돌려 달라고 하세요.
올렸는데 화면이 그대로예요캐시 비우기 → 플러그인 목록에서 버전(1.2.4.1 등)이 바뀌었는지 확인.
사이트 오류가 나요8번대로 원본 ZIP 으로 교체. 관리자가 안 열리면 플러그인 폴더 이름 바꾸기.
읽기 편하고 빨라지면 무조건 승인되나요?아닙니다. 특정 디자인이나 PageSpeed 점수는 애드센스 승인 기준표가 아닙니다. Google도 좋은 페이지 경험을 권하지만 점수만으로 상위 노출을 보장하지 않습니다. 공식 안내
강사용 검증 범위

3주차 프로그램(원본 ZIP 풀기·검사·설치 ZIP 만들기)은 실제 메킷애센 1.2.4 ZIP 으로 시험했습니다: 라이선스 함수 변경과 괄호 깨짐은 막고, 만든 ZIP 은 압축 검사를 통과하며 맨 위 폴더 이름·버전(1.2.4.1)이 맞습니다. 워드프레스에 실제로 올려 교체하는 것, Windows, 첫 수강생 완주는 아직 확인 전입니다.
