# 선택형 네이버 정보 이미지 기준

이 문서는 사용자가 제공한 이미지 프롬프트를 바탕으로, 네이버 글의 고정 3장 이미지에 적용하는 기준입니다.

## 이미지 선택
- 글마다 이미지는 정확히 3장만 만든다.
- 모든 소제목에 이미지나 도표를 넣지 않는다.
- 아래 주제에 해당하는 소제목을 우선 선택한다: 지원 대상·자격·조건, 신청·발급 절차, 제출 서류, 기한, 지원 금액·한도·혜택, 사용처, 주의사항·유의사항.
- 위 주제가 3개보다 적으면 남은 이미지는 해당 글을 이해하는 데 가장 도움이 되는 소제목의 간단한 장면 이미지로 만든다.
- 각 이미지는 선택된 소제목 하나만 설명한다. 다른 소제목의 정보는 섞지 않는다.

## 정보 이미지 스타일
- 흰색 또는 아주 밝은 배경, 넉넉한 여백, 큰 굵은 검은색 한글 제목.
- 남색·보라색·연한 파랑을 절제된 강조색으로 사용한다.
- 내용에 맞춰 비교표, 카드형 요약, 순서도, FAQ, 큰 숫자 중심 구성 중 하나를 고른다.
- 연속된 이미지가 같은 카드형 템플릿처럼 보이지 않게 한다.
- 모바일에서도 읽히도록 항목은 적게, 대비는 충분히, 글자는 크게 만든다.
- 장식용 인물·불필요한 아이콘·로고·상표·실존 인물 얼굴·저작권 캐릭터는 넣지 않는다.

## 내용 정확성
- 이미지에는 해당 소제목의 핵심만 표시한다.
- 제목·항목·숫자·날짜·금액·기관명은 글 본문에서 확인된 정보만 사용한다.
- 확인되지 않은 수치·자격 조건·기관명은 만들지 않는다.
- 이미지 안에 표시할 한글 문구는 프롬프트에 정확히 적는다.
- 한글 문구가 깨지거나 숫자·날짜·금액이 달라지면 다시 생성한다.

## 정보가 아닌 이미지
- 선택되지 않은 소제목에는 글자를 넣지 않은 단순한 장면형 일러스트를 사용한다.
- 정보 이미지의 디자인 규칙은 신청·대상·조건·서류·기한·금액·주의사항처럼 요약이 도움이 되는 소제목에만 사용한다.


## 소제목에 직접 답하는 정보 이미지

정보 이미지는 소제목의 제목만 크게 보여 주는 장식물이 아니라, 독자의 질문에 한 장으로 답하는 요약표여야 한다. 정보 이미지마다 제목 1개와 핵심 항목 3~5개를 반드시 표시한다.

- 대상·자격·조건: 누가 가능한지, 누가 제외되는지, 거주지·나이·소득·보유 조건을 본문에서 확인된 사실만 3~5개 항목으로 나열한다.
- 신청·발급 방법: 신청처 → 준비물 → 신청 또는 발급 → 수령·사용 순서처럼 실제 행동을 3~5단계 흐름도로 표시한다.
- 제출 서류: 필요한 서류를 체크리스트로 보여 준다. 공고마다 달라질 수 있는 서류는 ‘최신 공고 확인’으로 표시한다.
- 금액·한도·혜택: 지원 비율, 최대 금액, 월별 한도, 사용처 등 확인된 숫자를 큰 숫자·비교표·카드로 명확히 표시한다.
- 기한·주의사항: 신청 기간, 예산 소진, 선착순 여부, 재신청 제한, 사용 제한 등 놓치기 쉬운 내용을 경고형 체크리스트로 표시한다.

제목만 쓰거나 소제목과 무관한 장면을 넣지 않는다. 이미지 안의 모든 문구와 숫자는 해당 소제목 본문에서 확인된 사실만 사용한다. 확인되지 않은 나이, 금액, 날짜, 기관명, 전화번호는 절대 만들지 않는다.
