# 네이버 글 비용 보호 운영 규칙

## 목적

사실성·완성도를 포기하지 않으면서, 같은 글을 처음부터 반복 생성하거나 불필요한 이미지·검증·대기 호출로 OpenAI 크레딧과 토큰이 과도하게 쓰이는 일을 막는다.

## 공통 고정 흐름

입력 → 조사 → 사실 검증 → 제목 3개와 핵심 키워드 10개 제안 → 원고 작성 → 원고 검증 → 네이버 임시저장

제목 3개는 발행 전 사용자가 고를 수 있다. 각 제목이 약속한 답은 같은 원고 안에 검증 가능한 근거와 함께 반드시 들어 있어야 한다.

## 사실 오류 대응

- 사실, 날짜, 인물 관계, 방송 내용, 정책 조건처럼 내용의 진위가 문제이면 해당 주장과 직접 관련된 신뢰할 수 있는 자료를 다시 조사한다.
- 재조사는 문제가 된 주장에만 한정한다. 이미 확인된 다른 사실, 제목, 완성된 본문 전체를 다시 생성하지 않는다.
- 재조사 결과가 기존 주장과 다르거나 근거가 부족하면 해당 문장과 제목 후보에서 그 주장을 삭제하거나 검증된 표현으로 교체한다.
- 개인의 사생활·가족관계·추정·커뮤니티 소문은 공식 발표 또는 복수의 신뢰할 수 있는 보도가 없으면 사실처럼 쓰지 않는다.
- 조사 실패 또는 검증 실패를 이유로 근거 없는 문장을 유지하지 않는다.

## 비용·토큰 제한

- 스타·연예·방송 이슈 글은 이미지를 만들지 않는다.
- 제목 3개와 핵심 키워드 10개는 한 번의 모델 호출로 함께 만든다.
- 글이 짧다는 이유만으로 원고 전체를 자동 재생성하지 않는다.
- 원고 검증 뒤 자동 수정은 최대 한 번만 한다. 같은 원고를 두 번 이상 자동 재작성하지 않는다.
- 형식 오류, 네이버 입력 오류, 임시저장 오류는 저장된 원고를 그대로 다시 입력한다. 조사·제목·원고 생성을 다시 호출하지 않는다.
- 네이버 입력을 여러 조각으로 나누는 경우에도 앞 단계 결과를 재사용하고, 완료를 기다리는 중복 호출을 하지 않는다.
- 실제 사용자 글을 이용해 비용이 드는 시험 생성·재생성을 하지 않는다.
- 생성 중 문제가 생기면 완료된 단계의 결과를 보존하고, 문제가 난 단계부터 한 번만 복구한다.

## 기록과 확인

- 새 원고마다 모델 호출 수, 입력 토큰, 출력 토큰, 모델별 사용량을 원고 기록에 저장한다.
- 핵심 키워드 10개는 본문에 넣지 않는다. 네이버 임시저장 뒤 각 키워드 앞에 #을 붙인 해시태그로 별도 안내한다.
- 과거 원고에 사용량 기록이 없으면 정확한 사용량을 추정하거나 지어내지 않는다.
- 실제 청구 금액은 OpenAI Platform의 사용량·청구 기록을 기준으로 확인한다. 원고 기록은 글별 사용량을 비교하고 다음 생성 비용을 관리하기 위한 보조 기록이다.

## 주제별 적용

### 스타·연예·방송 이슈

- 방송사·제작진·소속사·공식 채널 및 복수의 신뢰할 수 있는 보도를 조사한다.
- 독자가 궁금해할 방송의 장면, 발언, 선곡, 대결, 결과를 사실 중심으로 설명한다.
- 작성자 경험은 개인적 반응으로만 쓰고, 기사나 사실의 근거로 사용하지 않는다.
- 이미지 생성은 하지 않는다.

### 정부정책

- 정부·지자체·공공기관의 최신 공식 공고와 안내를 우선한다.
- 대상, 지원 내용, 신청 방법, 기한, 필요 서류, 유의사항을 확인 가능한 근거로 정리한다.
- 이미지가 필요한 경우에만 본문에서 검증된 정보로 만든 정보형 이미지를 사용한다.
