# GEO·AEO: 답을 이해하고 근거를 확인할 수 있는가
이 자료는 AI 인용 확률을 계산하는 공식이 아니다. Google, ChatGPT, 다른 검색 서비스의 동작을 하나로 일반화하지 않는다.

사용자의 질문과 페이지가 실제로 답하는 내용을 대조한다. 다음 중 필요한 변경만 제안한다.
- 긴 본문이라면 핵심 답변과 적용 조건을 눈에 띄게 정리.
- 숫자·정책·가격·기간 등은 확인 가능한 출처와 기준일을 연결.
- 경험과 객관적 사실을 구분. 실제 작성자·검토자 정보를 사용.
- 질문형 제목·표·목록은 내용 이해에 도움이 될 때 선택. 정해진 글자 수·FAQ 수를 강요하지 않음.
- 플러그인은 작성자가 입력하는 요약·출처·검토일 표시를 제공할 수 있다. 부족한 사실을 대신 만들어내지 않음.
- llms.txt나 전용 스키마를 Google 생성형 검색의 필수 조건으로 판매하지 않음.
- 크롤러 접근 허용은 개인정보·콘텐츠 정책과 연결됨. 검색 크롤러와 학습 크롤러를 구분하고 일괄 허용하지 않음.
- 실제 인용 확인은 관찰 일시·질문·서비스·링크를 기록. 단일 관찰을 일반적 노출 보장으로 표현하지 않음.
