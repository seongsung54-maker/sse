# 읽기 편함과 모바일 화면
읽기 쉬운 화면을 만드는 작업이다. 특정 글자 크기·간격·색상이 Google의 승인 공식이라고 설명하지 않는다.

## 작업 전
학생이 지정한 글 페이지와 플러그인 버전, 적용 테마를 확인한다. 화면과 실제 계산 스타일을 연결해 본문·목차·관련 글의 스타일 소유자를 찾는다. 같은 페이지를 데스크톱과 좁은 화면에서 보관한다. 원문 글·제목·URL을 변경할 필요가 없는 작업이라면 그대로 유지한다.

## 변경 선택
- 학생이 작다고 한 본문·제목만 읽기 편한 크기로 조정한다. 페이지 전체의 h1/h2 태그를 임의 교체하지 않는다.
- 줄 간격·문단 여백·본문 폭을 함께 보고 긴 문장과 목록도 확인한다. 숫자는 사용자 요구와 실제 화면에 따라 정하며 고정 SEO 기준으로 쓰지 않는다.
- 모바일의 가로 넘침·겹치는 목차·눌리기 어려운 링크를 확인한다. 본문이나 광고를 숨겨 넘침을 감추지 않는다.
- 대비와 링크 구분, 키보드 포커스를 확인한다. 대체 텍스트는 이미지 용도에 맞춰 판단하고 키워드를 반복 삽입하지 않는다.
- 이미지 크기를 조정할 때 비율·실제 로드·대체 상태를 함께 확인한다.

## 검증과 전달
같은 URL·내용·화면 폭에서 전후 캡처, 계산된 글자 크기·간격, 넘침, 링크·목차 동작을 기록한다. 글 내용·기존 검색 관련 출력이 유지되는지 별도로 확인한다. 읽기 편해 보이는 것과 실제 사용자가 더 잘 읽는 것은 다른 증거다. 필요한 경우 학생에게 직접 읽고 선택하게 한다.

소스 담당이 테마라면 그 사실을 설명한다. 플러그인에 전역 강제 스타일을 누적해 덮지 않는다. 이번 플러그인 작업 범위 안에서 가능한지, 테마 수정 승인이 필요한지 구분한다.
