# 3주차: 받은 메킷애센을 내 방식으로 업그레이드
학생이 받은 정식 플러그인 ZIP 으로 진행한다. 공개 저장소에는 메킷애센 원본이 없다. 작업은 키트 폴더 안 `메킷애센 수정/` 에서만 하고, 1·2주차 자동화 폴더와 파일은 건드리지 않는다.

## 수업의 경계
학생이 선택한 기존 플러그인의 기능·표현을 고치는 실습이다. 새 WordPress·게시글·콘텐츠를 만드는 수업으로 전환하지 않는다. 연습용 WordPress 준비는 실행 검사 환경 마련이지 사이트 제작 결과물이 아니다. 참고 자료의 넓은 점검 항목을 이번 수업의 필수 과제로 확장하지 않는다.

## 학생 선택 → 현재 상태 → 한 가지 변경 → 전후 확인
- 읽기 편하게: 현재 글자·줄 간격·문단·본문 폭과 변경 담당 파일을 확인한다. 원문과 제목·링크는 유지한다.
- 모바일 보기 좋게: 기존 목차·관련 글·이미지 중 학생이 고른 영역만 고친다. 새로 중복 생성하지 않는다.
- 속도 개선: 같은 페이지의 측정 자료를 받고 원인을 플러그인 소유 자원과 나머지로 나눈다. 플러그인 안에서 해결 가능한 항목 하나부터 진행한다.

학생이 이미 고른 요구를 전체 감사나 강사의 고정 디자인으로 바꾸지 않는다. 무엇을 고칠지 모르면 실제 확인된 후보와 눈에 보일 변화, 검증 방법을 짧게 제시한다. 화면이나 소스가 없으면 필요한 자료 하나부터 요청한다.

라이선스·초기화·광고·수익 측정·홈페이지 생성 기능은 가독성/모바일/속도 실습에서 임의 변경하지 않는다. 광고를 지워 속도 점수만 높이지 않는다. 기본 결과물은 기존 메킷애센의 교체용 개인 수정본이며 기존판과 동시 활성화하지 않는다.

## 실제 시연 이력과 활용
v0.1.0 로컬 시험에서는 기존 관련 글 영역들을 카드 하나로 통합한 수정본을 검증했다. 이는 가능한 개선 예시 하나이지 모든 사이트의 필수 개선이나 속도·애드센스 승인 효과 증거가 아니다.
현재 버전의 출력 경로를 다시 확인한다. 관련 글 수·선정 기준 변경은 단순 디자인 변경과 구분한다. 대표 이미지 없는 글에는 가짜 URL을 만들지 않는다.

새 가독성 예시는 설명용 모형과 실제 WordPress 캡처를 구분한다. 속도 자료가 없으면 수치를 채우지 않는다. 결과에는 변경 파일·원문 유지 여부·화면 전후·검사·미확인 항목·원복 방법을 남긴다.

공개 독립 연습 플러그인은 별도 참고 예제다. 수강생이 가진 메킷애센을 대신 설치하도록 기본 경로를 바꾸지 않는다.
